## R1: participant encoding

Conclusion: the observed encoding is `participant_count = number of valid visible BIC occurrences`, excluding each literal `...`. Agreement is 10,000,000 / 10,000,000. It holds in both early/late periods (split July 1 UTC), all three route types and both continuity flags. The deciding comparison is visible occurrence count versus distinct count on repeated-BIC paths: A and B independently find the same 59,191 exceptions to distinct counting, with matching route/continuity subgroup counts. The lead should compare those exact grouped totals, not percentages alone.

Limit: this is a deterministic relationship in the supplied finite population, not proof of the generator's implementation or of the true hidden institution count. Gaps remain unobservable. A plausible business interpretation is a count of observed processing appearances, but the data cannot prove that interpretation. Do not call it an exact number of distinct participating banks.

## R1b: gap and continuity

Conclusion: `continuity_qflag = N` if and only if the observed path has a literal gap marker: 767,204 / 767,204 N paths have gaps and zero Y paths do. Both reviewers' calendar/period subgroup checks support this boundary. The deciding comparison is the 2-by-2 gap-present versus continuity table, with route and temporal repetitions to rule out an aggregate-only coincidence.

Strongest limitation: this exact gap flag relationship does not validate ordering/beneficiary endpoints. Thus an explanation that all routing diagnostics merely reflect omitted institutions is contradicted. The lead should independently verify these Y endpoint counts from its flag cross-tab; no new full-file scan is needed.
