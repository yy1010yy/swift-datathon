with a nearest-earlier blank same-sender/currency control. Measure recipient-account
and BIC novelty, amount rank and ratio, exact amount reuse, lags, and exact reverse-

an ordinary first payment. A recall mechanism requires more than the label name.

## Correspondent choice

For each non-Direct path, predict the first and last visible intermediary BIC using
only pre-July counts, then score July. Compare global, currency, sender/receiver country,
country-pair, exact endpoint BIC and exact endpoint-pair models with explicit unseen
fallback. Stable conditional concentration supports preferred correspondent pools;
failure after sparse controls is an informative negative result.
